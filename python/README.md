# Tower Defence

2D top-down tower defence на pygame. Проект на uv.

## Управление

| Действие | Управление |
|---|---|
| Выбрать башню в панели | ЛКМ по кнопке внизу / клавиши `1`, `2` |
| Установить башню | ЛКМ по пустой клетке → радиальное меню → ЛКМ по сектору |
| Удалить башню | ЛКМ по башне → красная кнопка Delete → ЛКМ по ней |
| Запустить волну | ЛКМ по зелёной кнопке у входа / `SPACE` |
| Рестарт | `R` при Game Over |

## Путь

Змейка через всё поле, 8 waypoints. Длина пути ~1600 px. Враги проходят за ≈18 секунд.

```
⤷  (200,260) → (200,100) → (460,100) → (460,420) → (700,420) → (700,180) → ⤶
```

## Башни

| Параметр | Rapid | Cannon |
|---|---|---|
| Цена | 100 | 250 |
| Урон | 10 | 60 × 5 снарядов |
| Интервал | 10 кадров (0.17 с) | 75 кадров (1.25 с) |
| DPS | 60 | 240 (если все попадают) |
| Радиус | 150 px | 120 px |
| Цвет | Cyan | Orange |
| Снаряд | 6 px/кадр, радиус 3 | 6 px/кадр, радиус 6 |

**Rapid** — дешёвая, быстро стреляет, малый радиус. Хороша против толпы слабых врагов.

**Cannon** — дорогая, короткий радиус. Стреляет 5 снарядов веером. Снаряды пробивают врагов насквозь (задевают всех на линии).

## Волны

Все волны используют единую формулу (бесконечный скейлинг):

| Параметр | База (волна 1) | Множитель за волну |
|---|---|---|
| Количество | 5 | `× (1 + (N-1) × 0.35)` |
| HP | 50 | `× (1 + (N-1) × 0.35)` |
| Скорость | 1.5 | `+ (N-1) × 0.05` |
| Награда за крипа | 8 | `+ (N-1) × 1.5` |

Примеры:

| Волна | Количество | HP | Скорость | Награда |
|---|---|---|---|---|
| 1 | 5 | 50 | 1.5 | 8 |
| 2 | 6 | 67 | 1.55 | 9 |
| 3 | 8 | 85 | 1.6 | 11 |
| 4 | 9 | 102 | 1.65 | 12 |
| 5 | 11 | 120 | 1.7 | 14 |
| 10 | 20 | 207 | 1.95 | 21 |

Интервал спавна крипов внутри волны: 25 кадров (0.42 с).

## Экономика

- **Стартовое золото**: 300
- **Награда за крипа**: зависит от волны (8–21+)
- **Бонус за ранний старт**: `30 / max(1, elapsed_seconds)`
  - Мгновенный старт: +30
  - Через 5 с: +6
  - Через 15 с (автостарт): +2
- **Жизни**: 3
  - Каждый крип, дошедший до конца пути, отнимает 1 жизнь
  - 0 жизней = Game Over

## Автостарт волны

Если не запустить волну вручную за 15 секунд, она стартует автоматически. Бонус за ранний старт в этом случае минимальный (+2).

## Клетки поля

Сетка 40×40 px, поле 20×15 клеток. Нижние 60 px — панель управления. Путь занимает 38 клеток, остальные доступны для строительства.

## Запуск

```bash
uv run python tower_defence.py
```
