# Tower Defence — Summary

## Стек

- Python 3 + pygame 2.6.1
- Управление зависимостями: uv
- Один файл: `tower_defence.py` (~510 строк)

## Архитектура

### Классы

**Enemy** — враг, движется по waypoints.
- Параметры: hp, speed, gold, waypoint_index
- При достижении последней точки — `reached_end = True` (отнимает жизнь)
- HP bar рисуется над врагом

**Projectile** — снаряд.
- Два режима:
  - **Homing** (Rapid): летит к цели, умирает при попадании
  - **Piercing** (Cannon): летит в заданном направлении, пробивает всех врагов на линии
- `hit_enemies` — set id() уже поражённых врагов (чтобы не дамажить дважды)
- `max_range` — умирает при выходе за радиус башни-владельца (проверка для обоих типов)

**Tower** — башня.
- `update()` возвращает список Projectile (пустой если на кулдауне или нет целей)
- Cannon создаёт 5 снарядов с веерным разлётом (spread = 0.35 rad)

**Game** — состояние игры, логика, отрисовка, обработка ввода.

### Рендеринг

- Поле 800×600, сетка 40×40, нижние 60px — UI-панель
- Всё рисуется через pygame.draw (без спрайтов и изображений)
- Радиальное меню установки (2 сектора: Rapid справа / Cannon слева)
- Радиальное меню удаления (красный круг с "Delete")
- Кнопка старта волны у входа пути (25, 260), зеленеет/краснеет по таймеру

## Механики

### Путь

Змейка: 8 waypoints, 38 клеток пути. Длина ~1600 px.

### Башни

| | Rapid | Cannon |
|---|---|---|
| Цена | 100 | 250 |
| Урон | 10 | 60 × 5 снарядов |
| Интервал | 10 fr (0.17s) | 75 fr (1.25s) |
| Радиус | 150 px | 120 px |
| Снаряд | homing, r=3 | piercing, r=6, веер ±0.7 rad |

### Волны (бесконечный скейлинг)

Формула от N = номер волны (1+):

- `count = int(5 × (1 + (N-1) × 0.35))`
- `hp = int(50 × (1 + (N-1) × 0.35))`
- `speed = 1.5 + (N-1) × 0.05`
- `gold = int(8 + (N-1) × 1.5)`

Спавн: 1 враг каждые 25 fr (~0.42s).

### Экономика

- Старт: 300 золота, 3 жизни
- Награда за крипа: 8–21+ (растёт с волнами)
- Бонус раннего старта: `30 ÷ max(1, elapsed_seconds)`
  - Мгновенный старт: +30
  - Через 5 с: +6
  - Автостарт (15 с): +2
- Башни не продаются (только удаление без возврата денег)

### Автостарт

15 сек бездействия → волна стартует автоматически.

### Управление

| Действие | Ввод |
|---|---|
| Выбрать башню | Клавиши 1/2 или ЛКМ по кнопке в UI |
| Установить | ЛКМ по пустой клетке → меню → сектор |
| Удалить | ЛКМ по башне → Delete → ЛКМ |
| Старт волны | SPACE или ЛКМ по кнопке у входа пути |
| Рестарт | R при Game Over |

## Известные проблемы / TODO

### ⚠️ Баланс (требуется итерация)

Текущие параметры подобраны на глаз, **баланс не оттестирован**. Основные вопросы:

1. **Rapid vs Cannon**
   - Rapid: 100g, 10dmg × 6/с = 60 DPS, радиус 150
   - Cannon: 250g, 60dmg × 5снар × 0.8/с = 240 DPS, радиус 120
   - Cannon даёт 4× DPS за 2.5× цену — возможно overshadows Rapid на толпах
   - Нужно решить: должна ли Cannon быть чисто situational (против бронированных/групп) или универсально сильной

2. **Scaling волн**
   - 0.35 множитель на count/HP может быть слишком крутым к волне 10+
   - Прирост скорости 0.05/волну незначителен до волны 20 (где будет 2.45 — всё ещё медленно)
   - Золото 8 + 1.5×N — к волне 10: 21g/крип, волна 20: 36g/крип — возможно слишком щедро для бесконечного скейлинга

3. **Piercing + 5 снарядов**
   - Каждый снаряд делает 60 dmg всем врагам на линии
   - На узких участках пути Cannon может hitting 3+ врагов одним снарядом → 180 dmg × 5 = 900 dmg за залп
   - Возможно нужен damage falloff или лимит pierce

4. **Экономика**
   - Стартовые 300g: 3×Rapid или 1×Cannon
   - После волны 1: +40g → можно 4-й Rapid
   - Возможно слишком мало вариантов в начале — только Rapid или копить на Cannon
   - Добавление дешёвой стартовой башни (~50g) могло бы улучшить early game

5. **Жизни**
   - 3 жизни, каждый крип снимает 1
   - К волне 5 бегут 11 крипов с 1.7 speed — один пропуск = -1
   - Слишком штрафно для новичка? Или нормально для TD?
