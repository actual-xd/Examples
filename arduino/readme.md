## Task 6
### Термометр с индикатором уровня.
Датчик TMP36 измеряет температуру. Четыре светодиода (синий/зелёный/жёлтый/красный) показывают уровень температуры.
Кнопка переключает единицы отображения °C / °F. Выбор сохраняется в EEPROM.

Файлы в папке: `task6_thermometer/`


## Task 5
### Светофор с кнопкой.
Двухрежимный светофор на трёх светодиодах (красный/жёлтый/зелёный) и кнопке.
Кнопка переключает между автоматическим режимом (цикл фаз светофора) и аварийным (мигание жёлтым).
Текущий режим сохраняется в EEPROM.

Файлы в папке: `task5_traffic_light/`


## Task 3
### NeoPixel Ring с переключателем и EEPROM.
Управление вращением светового фрагмента на NeoPixel кольце с помощью двухпозиционного переключателя.
Состояние сохраняется в EEPROM.

**Функционал:**
- **Левое положение:** яркий синий фрагмент вращается против часовой стрелки
- **Правое положение:** яркий красный фрагмент вращается по часовой стрелке
- Состояние (left/right) автоматически сохраняется в EEPROM
- Анимация работает непрерывно

Файлы в папке: `task3_neopixel_ring/`
