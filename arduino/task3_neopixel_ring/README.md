# Лабораторная работа 3: NeoPixel Ring с переключателем

## Описание
Проект демонстрирует управление NeoPixel кольцом (16 светодиодов) с помощью двухпозиционного переключателя (slide switch). Состояние переключателя сохраняется в энергонезависимую память EEPROM.

## Компоненты
- **Arduino Nano**
- **NeoPixel Ring** (16 светодиодов)
- **Slide Switch** (2-позиционный)

## Подключение

### NeoPixel Ring
- **VDD** → Arduino **5V**
- **GND** → Arduino **GND**
- **DI** (Data In) → Arduino **Pin 6**

### Slide Switch
- **Pin 1** (левый) → Arduino **GND**
- **Pin 2** (центральный) → Arduino **Pin 2**
- **Pin 3** (правый) → Arduino **5V**

## Логика работы

### Положения переключателя:
1. **Левое положение** (Pin 2 → LOW, подключен к GND):
   - Синий фрагмент из 4 светодиодов
   - Вращение против часовой стрелки
   - Состояние сохраняется в EEPROM

2. **Правое положение** (Pin 2 → HIGH, подключен к 5V):
   - Красный фрагмент из 4 светодиодов
   - Вращение по часовой стрелке
   - Состояние сохраняется в EEPROM

### EEPROM
- Адрес `0` хранит последнее состояние переключателя (LEFT или RIGHT)
- При включении Arduino восстанавливает последнее сохранённое состояние
- Анимация продолжается непрерывно

## Параметры настройки

В коде можно изменить:

```cpp
#define LED_COUNT 16           // Количество светодиодов в кольце
#define BRIGHTNESS 100         // Яркость (0-255)
const long animationInterval = 150;  // Скорость вращения (мс)
int segmentSize = 4;           // Размер вращающегося фрагмента
```

## Как запустить в Wokwi

1. Перейдите на [Wokwi.com](https://wokwi.com)
2. Создайте новый проект Arduino
3. Скопируйте содержимое `sketch.ino` в редактор кода
4. Нажмите на `diagram.json` и вставьте содержимое файла
5. Установите библиотеку Adafruit_NeoPixel (уже указана в dependencies)
6. Запустите симуляцию
7. Переключайте slide switch для управления кольцом

## Отладка

Откройте Serial Monitor (9600 baud) для просмотра:
- Статус запуска
- Последнее сохранённое состояние из EEPROM
- Изменения состояния в реальном времени

## Возможные улучшения

- Добавить больше цветов и анимаций
- Регулировать скорость вращения потенциометром
- Использовать несколько фрагментов одновременно
- Добавить режимы радуги или мерцания
- Сохранять также скорость и цвет в EEPROM
