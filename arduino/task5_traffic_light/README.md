# Лабораторная работа 5: Светофор с кнопкой

## Описание

Проект реализует двухрежимный светофор на трёх светодиодах (красный, жёлтый, зелёный) и одной кнопке.  
Текущий режим сохраняется в **EEPROM** и восстанавливается после перезагрузки.

## Компоненты

| Компонент         | Количество |
|-------------------|------------|
| Arduino Nano      | 1          |
| Светодиод красный | 1          |
| Светодиод жёлтый  | 1          |
| Светодиод зелёный | 1          |
| Резистор 220 Ом   | 3          |
| Кнопка (pushbutton) | 1        |

## Подключение

### Светодиоды (через резистор 220 Ом)
- **Красный:** Анод → R1 → Arduino **Pin 9** | Катод → **GND**
- **Жёлтый:** Анод → R2 → Arduino **Pin 10** | Катод → **GND**
- **Зелёный:** Анод → R3 → Arduino **Pin 11** | Катод → **GND**

### Кнопка
- **Pin 1** → Arduino **Pin 2**
- **Pin 2** → Arduino **GND**
- (Внутренний подтягивающий резистор `INPUT_PULLUP` — внешний не нужен)

## Логика работы

### Режим AUTO (автоматический светофор)

Светофор циклически проходит 4 фазы:

| Фаза            | Светодиоды           | Длительность |
|-----------------|----------------------|--------------|
| Красный         | 🔴 Красный           | 3 сек        |
| Красный+Жёлтый  | 🔴 Красный + 🟡 Жёлтый | 1 сек      |
| Зелёный         | 🟢 Зелёный           | 3 сек        |
| Жёлтый          | 🟡 Жёлтый            | 1 сек        |

### Режим BLINK (мигание — ночной/аварийный режим)

- Горит только жёлтый светодиод, мигая с интервалом **500 мс**

### Переключение режимов

- **Нажатие кнопки** переключает между режимами AUTO ↔ BLINK
- Режим сохраняется в EEPROM (адрес `0`) и восстанавливается при включении

## Параметры настройки

```cpp
const unsigned long phaseDuration[] = {
  3000,  // Красный (мс)
  1000,  // Красный + Жёлтый (мс)
  3000,  // Зелёный (мс)
  1000   // Жёлтый (мс)
};

const unsigned long BLINK_INTERVAL = 500; // Интервал мигания (мс)
```

## Как запустить в Wokwi

1. Перейдите на [Wokwi.com](https://wokwi.com)
2. Создайте новый проект Arduino Nano
3. Скопируйте содержимое `sketch.ino` в редактор кода
4. Нажмите на `diagram.json` и вставьте содержимое файла
5. Запустите симуляцию — светофор начнёт работать в режиме AUTO
6. Нажмите синюю кнопку для переключения в режим BLINK и обратно

## Отладка

Откройте **Serial Monitor** (9600 baud) для просмотра:
- Режима, восстановленного из EEPROM при запуске
- Сообщений о переключении режима при нажатии кнопки
