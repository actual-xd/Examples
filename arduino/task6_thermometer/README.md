# Лабораторная работа 6: Термометр с индикатором уровня

## Описание

NTC термистор измеряет температуру. Четыре светодиода показывают уровень температуры.
Значение в °C выводится в Serial Monitor каждую секунду.

## Компоненты

| Компонент              | Количество |
|------------------------|------------|
| Arduino Nano           | 1          |
| Датчик NTC (термистор) | 1          |
| Светодиод синий        | 1          |
| Светодиод зелёный      | 1          |
| Светодиод жёлтый       | 1          |
| Светодиод красный      | 1          |
| Резистор 220 Ом        | 4          |

## Подключение

### Датчик NTC
- **VCC** → Arduino **5V**
- **GND** → Arduino **GND**
- **OUT** → Arduino **A0**

### Светодиоды (через резистор 220 Ом)
- **Синий:**   Анод → R1 → Arduino **Pin 5** | Катод → **GND**
- **Зелёный:** Анод → R2 → Arduino **Pin 6** | Катод → **GND**
- **Жёлтый:**  Анод → R3 → Arduino **Pin 7** | Катод → **GND**
- **Красный:** Анод → R4 → Arduino **Pin 8** | Катод → **GND**

## Логика работы

| Светодиод  | Диапазон      |
|------------|---------------|
| 🔵 Синий   | < 20 °C       |
| 🟢 Зелёный | 20 °C – 29 °C |
| 🟡 Жёлтый  | 30 °C – 39 °C |
| 🔴 Красный | ≥ 40 °C       |

## Формула NTC термистора

```cpp
const float BETA = 3950;
int raw = analogRead(A0);
float celsius = 1.0 / (log(1.0 / (1023.0 / raw - 1)) / BETA + 1.0 / 298.15) - 273.15;
```

## Как запустить в Wokwi

1. Создайте новый проект Arduino Nano на [Wokwi.com](https://wokwi.com)
2. Вставьте содержимое `sketch.ino` в редактор кода
3. Вставьте содержимое `diagram.json` в схему
4. Запустите симуляцию
5. Перетащите ползунок температуры на датчике NTC и наблюдайте переключение светодиодов
6. Откройте Serial Monitor (9600 baud) для просмотра точных значений
